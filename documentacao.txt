
DOCUMENTAÇÃO DO PROJETO

Nome: VITRIXX

Tema: Loja Virtual Automotiva.

Objetivo:
Criar uma loja virtual simples para apresentar produtos automotivos e permitir o gerenciamento de clientes, produtos e pedidos.

ENTIDADES:

Produtos:
- ID
- Nome
- Preço

Clientes:
- ID
- Nome
- Contato

Pedidos:
- ID
- Cliente
- Produto
- Quantidade
- Valor total

FUNCIONALIDADES:

- Visualização de produtos.
- Cadastro de produtos.
- Edição de produtos.
- Exclusão de produtos.
- Cadastro de clientes.
- Edição de clientes.
- Exclusão de clientes.
- Cadastro de pedidos.
- Edição de pedidos.
- Exclusão de pedidos.
- Login administrativo.

TECNOLOGIAS:

- HTML
- CSS
- JavaScript
- LocalStorage
